What it does

The desktop as another enrolled device

Opens from the site

“Open on this device” hands the thessleypasskey:// link to the app. It shows the site and origin, and asks approve or deny.

Enrols like a phone

Profile → Add a device → Open on this device → name it → choose how the key is protected.

Works with both servers

The WordPress plugin and the Drupal module accept this app unchanged.

Revocable centrally

The site lists the computer under Thessley Passkey devices; revoke it there.

thessleydesktop approver
Key protection

Five ways, in order of strength

TPM + PIN

Key inside the TPM 2.0 chip; it cannot be copied off the machine. PIN to use it.

TPM + PIN + key

Same, plus a touch of a FIDO2 security key.

PIN

Software key, encrypted; scrypt of the PIN.

Security key

Software key, encrypted; the key’s hmac-secret and a touch.

PIN + key

Both are required to sign.

Same protocol

The site verifies exactly what it verifies for a phone.

thessleythe TPM option is first when the machine has one
Requirements

Modest, and written down

  • Python 3.10+, GTK 4 and libadwaita 1.5+ (Ubuntu 24.04 or newer).
  • python-fido2 1.2+ for security keys; python3-asn1crypto only for the TPM option.
  • ./install.sh installs per user and registers the link handler; ./uninstall.sh --purge removes keys too.
  • Windows 11 is covered too — see WINDOWS.md.
