Design

Why it is not a PAM module

No PAM on Windows

OpenSSH for Windows offers no PAM hook, so the gate runs as the command the server starts after authentication.

ForceCommand

A small gate process asks the local service, then replaces itself with the real shell or command.

SYSTEM service

Approvers and passes live in ProgramData, owned by a service the logged-in account cannot rewrite.

Approve

4

Shell

The gate starts the requested shell or command, or refuses.
